CodeAlpha Stock Trading Platform

1. Project Overview

The Stock Trading Platform is a Java-based console application that simulates basic stock market operations. It allows users to view available stocks, buy and sell shares, manage their portfolio, and track transactions.

2. Features

View Market Stocks

- Display available company stocks.
- Show current stock prices.

Buy Stocks

- Select a stock from the market.
- Enter the quantity to purchase.
- Check available account balance.
- Update balance and stock holdings.

Sell Stocks

- Select a stock to sell.
- Enter the quantity.
- Check available shares.
- Update account balance after selling.

View Portfolio

- Display owned shares.
- Calculate stock value.
- Display total portfolio value.
- Calculate profit or loss.

Transaction History

- Display all buy and sell transactions.
- Show stock name, quantity, amount, date and time.
